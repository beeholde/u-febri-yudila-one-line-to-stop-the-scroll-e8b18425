Entry for the make.fun bounty [One Line to Stop the Scroll](https://make.fun/bounty/u-febri-yudila-one-line-to-stop-the-scroll-e8b18425): a program that writes one line of text to `/output/entry.txt` — one line that makes a stranger stop scrolling and smile.

## The line

> I waved back at a stranger who was waving at someone behind me, and we both committed to it for a full three seconds.

## Run

`python3 main.py` writes the line to `/output/entry.txt` (117 characters, UTF-8, no trailing newline).
